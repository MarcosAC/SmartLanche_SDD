# SmartLanche — Protótipo Web

Protótipo frontend para apresentação do sistema de gerenciamento de lanchonete.

## Tecnologias

- HTML5
- CSS3
- JavaScript (ES Modules)
- Local state em memória para demonstração

## Executar

Por usar módulos JavaScript (`type="module"`), recomenda-se abrir com um servidor HTTP local.

### VS Code

Instale a extensão **Live Server** e abra `index.html` com **Open with Live Server**.

### Python

Na pasta do projeto:

```bash
python -m http.server 5500
```

Depois acesse:

```text
http://localhost:5500/
```

## Módulos

- Dashboard
- Pedidos e Valor Final
- Promoções
- Pendências
- Pedidos em Preparação
- Estoque
- Resumo de Vendas

## Observação

Este projeto é um protótipo. Não possui backend, banco de dados, autenticação ou integrações reais.
